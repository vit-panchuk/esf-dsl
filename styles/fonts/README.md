# Fixel

Fixel, commissioned by MacPaw and designed at AlfaBravo. Three faces: the
display Black that the headings shout in, the display SemiBold Italic that
is the system's one oblique, and the text SemiBold Italic.

  Software to be distributed entirely under the OFL and no other licence.
